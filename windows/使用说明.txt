八千代 Windows 动作服务

安装位置：E:\YachiyoMotion
模型：DiP + DistilBERT，与 Ubuntu 当前使用的本地实时动作服务相同。无需 Llama 授权。

1. 首次安装.cmd：首次配置独立运行环境和下载公开模型。已配置后不用重复安装。
2. 启动动作服务.cmd：加载显卡上的动作模型，启动后后台运行。
3. 关闭动作服务.cmd：停止本目录的动作服务并释放模型显存；关闭启动窗口本身不会停止后台服务。
4. 查看动作服务状态.cmd：确认已启动或已关闭。

服务只监听本机 127.0.0.1:8787，Mac 可通过 SSH 转发使用。没有添加防火墙规则或开机自启。
模型在 models，独立 Python 在 runtime，运行日志在 logs，手动验证记录在 state。

本目录仅含动作服务，不含 Unity 角色模型或 Windows Unity 客户端。
